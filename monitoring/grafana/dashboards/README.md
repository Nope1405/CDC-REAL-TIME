# Grafana dashboards

Provisioned automatically (`monitoring/grafana/provisioning/`) into the **CDC**
folder when the `monitoring` profile is up: <http://localhost:3000>.

- `cdc-pipeline.json`: headline stats (p95 commit→indexed lag, docs/s,
  consumer lag, Debezium behind-source, WAL retained, DLQ), lag percentiles,
  p95 per stage, bulk latency, throughput, consumer lag per topic, WAL per
  slot, errors, DLQ and the Elasticsearch back-pressure pause.

The JSON is generated by `monitoring/grafana/build_dashboard.py`. Edit the
script and re-run it instead of hand-editing the JSON. Changes made in the
Grafana UI are allowed but are not written back to disk.
